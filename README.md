# Ebonmane Ink Creative Studios 🦁✒️

> _Where Roaring Creativity Meets the Stroke of Ink_

Welcome to the digital home of Ebonmane Ink Creative Studios — a passion project that bridges the worlds of storytelling, game design, and software engineering. This repository showcases a modern, responsive website built with clean HTML, modular CSS, and thoughtful design principles.

## 🎯 About This Project

This website represents my journey as an aspiring software engineer who believes in the power of narrative-driven experiences. Built from the ground up using semantic HTML and component-based CSS architecture, it demonstrates both technical proficiency and creative vision.

### 🛠️ Technical Highlights

- **Clean, Semantic HTML5** with accessibility best practices
- **Modular CSS Architecture** using BEM methodology
- **Responsive Design** that works beautifully across all devices
- **CSS Custom Properties** for maintainable theming
- **Component-Based Structure** for scalability
- **Performance Optimized** with minimal dependencies
- **Accessibility First** approach with proper ARIA labels and keyboard navigation

## 🎨 Design Philosophy

The website embodies a dark, elegant aesthetic inspired by Gothic literature and fantasy storytelling:

- **Royal Gold** (#f9c74f) - Representing creativity and inspiration
- **Night Purple** (#2e1a47) - The mystery of untold stories
- **Ink Blue** (#264653) - The depth of narrative possibility
- **Ebon Black** (#000000) - The canvas upon which stories are written

## 🚀 Features

### Multi-Page Architecture

- **Home Page**: Showcasing services, philosophy, and community engagement
- **Projects Portfolio**: Interactive filtering system for categorizing work
- **Journal/Blog**: Clean, readable layout for sharing insights and stories

### Interactive Elements

- Smooth hover animations and transitions
- JavaScript-powered project filtering

### Developer-Friendly Code

- Clear file organization and naming conventions
- Comprehensive commenting and documentation

│   ├── pillars.css        # Core values section

│   └── footer.css         # Footer styles

│   ├── projects.html      # Projects portfolio
